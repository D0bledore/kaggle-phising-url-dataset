# Phishing URL Detection Project

## Dataset Source

**Dataset:** Phishing Website Detection Datasets
**Author:** Md Sultanul Islam Ovi
**Platform:** Kaggle
**URL:** https://www.kaggle.com/datasets/mdsultanulislamovi/phishing-website-detection-datasets

### Description

Comprehensive phishing detection datasets collection featuring diverse URL analysis approaches for cybersecurity machine learning research. Contains 6 datasets with varying feature extraction approaches, ranging from 10,000 to 235,795 samples.

## Business Context

This project develops a phishing URL detection tool for a small security consulting firm. The goal is to enable staff to quickly assess URL safety and understand why a URL is flagged as risky (explainability is key for security awareness training).
